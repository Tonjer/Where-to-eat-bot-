# Where-to-eat-bot

Консольное приложение на Java для поиска ресторана («Где поесть?»). Приложение загружает список ресторанов из JSON-файла и позволяет фильтровать их по кухне, блюдам и среднему чеку.

## Возможности

- Загрузка данных о ресторанах из `src/main/resources/restaurant.json` (библиотека Jackson)
- Интерактивное консольное меню с командами
- Фильтрация ресторанов:
    - по кухне (`CuisineFilter`)
    - по блюдам (`DishFilter`)
    - по среднему чеку (`PriceFilter`)
    - комбинация фильтров (`CompositeFilter`)
- Вывод результатов в консоль

## Требования

- JDK 25
- Maven

## Сборка и запуск

```bash
mvn clean package
java -jar target/Where-to-eat-bot-1.0-SNAPSHOT.jar
```

Или запустите класс `bot.wheretoeat.Main` напрямую из вашей IDE.
